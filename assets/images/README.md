# Imagens da loja

Esta pasta destina-se às imagens da landing page **Beleza Brasil e China**.

Coloque aqui fotografias de produtos, banners e outras imagens da loja.

**Organização recomendada:**
- `produto-nome.webp` — fotografia de cada produto.
- `banner-principal.webp` — imagem principal da página.
- `categoria-cabelo.webp` — imagem de categoria.

Use nomes de ficheiros em minúsculas, sem espaços e com hífenes. Prefira imagens WebP ou AVIF optimizadas para telemóvel; mantenha o texto alternativo adequado em cada imagem HTML.

**Exemplo de utilização:**

```html
<img src="assets/images/produto-nome.webp" alt="Descrição do produto" loading="lazy">
```

Nota: adicionar imagens à pasta não as associa automaticamente ao catálogo. É necessário referenciar cada ficheiro no `index.html`.
